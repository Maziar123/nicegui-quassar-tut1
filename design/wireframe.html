What changes on small screens

  • Under 1020 pxThe intro, the step grid, the notes and the takeaways all become one column. The browser view and the layer stack stop being sticky.
  • Under 520 pxThe side gutter shrinks from 24 to 16 px and the "Vue → NiceGUI" brand is hidden. Each layer card puts the row name above the layer name, and the arrows move left.
  • Always scrolls sidewaysThe step bar chips, long code lines and the compare table (min 820 px wide) scroll inside their own box, so the page itself never scrolls sideways.

Notes: where each part is built

  1. Step barSticky top bar with a brand and one chip per step. Chips come from nav in build.py and go into <!--NAV-->. An IntersectionObserver marks the chip of the section you are reading.
  2. Intro, leftKicker, H1, lead text, the "road" of five stops and the colour legend. This is static markup in template.html.
  3. Intro, right: hero viewA fake browser with the two rectangles. view_html() fills <!--HERO_VIEW-->.
  4. Step headerNumber badge, H2 title, stack and file name, then the goal. Built by step_html() from STEPS[n]. All five sections go into <!--STEPS-->.
  5. Code column (1.2 fr)One or two code blocks from render_code(). The top bar has the file name, language, the "+ new in this step" key and a Copy button. Lines new since the last step get a green edge. Lines picked by a layer get a yellow highlight and the rest fade.
  6. Side column (1 fr, sticky)"What the browser shows" view, then the layer stack. It stays in view while the code scrolls past.
  7. Layer stackFive rows: Your code, Server, Element tree, Renderer, Browser. Built by layer_html() and arrow_html(). A layer with code refs is a button. Hover or focus previews its lines, and a click pins them. An unused layer is a dashed ghost box. The line ranges come from find_range() text markers.
  8. Notes row (1.5 : 1 : 0.9)"What the code does" (new_points), "Run it" (run plus optional cmds) and "Try it" (tryit, tinted green).
  9. Compare sectionSection 6. A matrix with a row-label column and four roads, coloured by layer role, plus four fact rows (the line counts come from loc()). Built by compare_html() into <!--COMPARE-->.
  10. TakeawaysThree note cards. This is static markup in template.html.
  11. FooterThe tested versions and advice on pinning a CDN version. Static.
