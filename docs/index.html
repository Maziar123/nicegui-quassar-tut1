Look at cross-comments 3 and 5. Quasar and NiceGUI do two jobs for you that plain Vue has to write by hand. The notes below the screenshot explain why.

Quasar

Why the border goes inside

A browser counts the border outside the width by default. Then a 200 px box with a 2 px border is 204 px wide. box-sizing: border-box puts the border inside, so the box stays 200 px.

Quasar turns this on for every element, so NiceGUI has it too. In plain Vue you write it yourself. Here is the difference with a thick 8 px border, so you can see it:

How each column reaches the browser

All three files end as the same page, but they take different roads. NiceGUI is the only one with a server: your Python runs there, and the browser gets the page from it.

1.2

Two boxes side by side

Open this step on its own page ↗

Put two of the boxes from step 1.1 next to each other, with 16 px of space between them.

The new idea is a row: a box that puts its children side by side. All three columns use the same CSS underneath, called flexbox.

Look at cross-comments 2 and 4. NiceGUI's row already has the gap and the wrapping. Quasar has the wrapping. Plain Vue writes both.

Quasar's row class turns a plain div into a row. The gap is not part of it, so it goes in style.

NiceGUI nicegui_app.py · Python · 12 lines

ui.row() is the row. Everything indented under with goes inside it. No gap to write: NiceGUI rows have one.

1from nicegui import ui2 3BOX = 'width: 200px; height: 120px; border: 2px solid #333'54 5 6def root():7    with ui.row():18        ui.element('div').style(BOX)  # left39        ui.element('div').style(BOX)  # right310 11 12ui.run(root, title='1.2 Two boxes side by side (NiceGUI)')

Quasar

A row is flexbox

display: flex turns a box into a row: its children line up side by side. Two more lines give it the gap and the wrapping. Quasar's row class and NiceGUI's ui.row() are this CSS with a name.

Here are three rows in a box only 380 px wide. The first has no gap, the second has a gap, and the third also wraps, so its last box moves to a new line:
