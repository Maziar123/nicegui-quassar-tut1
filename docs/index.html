1

One empty rectangle

HTML + Vue 3 · step1-empty-rectangle.html

Draw a single empty box with Vue 3. One file, no install, no build step.

step1-empty-rectangle.html HTML 
<!DOCTYPE html><html lang="en"><head>  <meta charset="UTF-8">  <meta name="viewport" content="width=device-width, initial-scale=1.0">  <title>Step 1 – Empty Rectangle (Vue 3)</title>  <style>    .rect {      width: 200px;      height: 120px;      border: 2px solid #333;    }  </style></head><body>  <!-- Vue renders inside this element -->  <div id="app">    <div class="rect"></div>  </div>   <script type="module">    import { createApp } from 'https://unpkg.com/vue@3/dist/vue.esm-browser.prod.js'     createApp({}).mount('#app')  </script></body></html>

What the code does

  • .rect gives the box its size (width, height) and its outline (border). Nothing inside it, so it stays empty.
  • <div id="app"> is the part of the page Vue controls. Everything inside it is Vue's template.
  • import { createApp } from … loads Vue as a modern ES module. vue@3 always resolves to the newest Vue 3 release (3.5.44 today).
  • createApp({}).mount('#app') starts an app with no data yet and attaches it to #app.

Run it

Save the file and open it in Firefox or Chromium.

It needs internet once, to fetch Vue from the CDN.

Try it

Change height to 60px and border to 2px dashed #333, then reload.

Put two boxes next to each other in one row, with a small gap between them.

<!DOCTYPE html><html lang="en"><head>  <meta charset="UTF-8">  <meta name="viewport" content="width=device-width, initial-scale=1.0">  <title>Step 2 – Two Rectangles Side by Side (Vue 3)</title>  <style>    .row {      display: flex;  /* side by side in one row */      gap: 16px;      /* small space between them */    }     .rect {      width: 200px;      height: 120px;      border: 2px solid #333;    }  </style></head><body>  <div id="app">    <div class="row">      <div class="rect"></div>  <!-- left -->      <div class="rect"></div>  <!-- right -->    </div>  </div>   <script type="module">    import { createApp } from 'https://unpkg.com/vue@3/dist/vue.esm-browser.prod.js'     createApp({}).mount('#app')  </script></body></html>

3

The same page in NiceGUI

Python + NiceGUI 4.0 · step3_nicegui.py

Write the same two rectangles in Python. NiceGUI builds the page and sends it to the browser.

step3_nicegui.py Python 
from nicegui import ui RECT = 'width: 200px; height: 120px; border: 2px solid #333'  def root():    with ui.row().style('gap: 16px'):   # flex row, side by side        ui.element('div').style(RECT)   # left        ui.element('div').style(RECT)   # right  ui.run(root, title='Step 3 – NiceGUI (Python)')
What NiceGUI sends to the browser (captured from a real run) JSON 
{  "0": {"tag": "q-layout", "class": ["nicegui-layout"], "props": {"view": "hhh lpr fff"}, "children": [1]},  "1": {"tag": "q-page-container", "children": [2]},  "2": {"tag": "q-page", "children": [3]},  "3": {"tag": "div", "class": ["nicegui-content"], "children": [4]},  "4": {"tag": "div", "class": ["nicegui-row", "row"], "style": {"gap": "16px"}, "children": [5, 6]},  "5": {"tag": "div", "style": {"width": "200px", "height": "120px", "border": "2px solid #333"}},  "6": {"tag": "div", "style": {"width": "200px", "height": "120px", "border": "2px solid #333"}}}

What the code does

  • with ui.row(): is the .row flex box. Anything created inside the with block becomes its child.
  • ui.element('div').style(RECT) is one <div class="rect">.
  • ui.run(root) replaces createApp().mount(). It starts a web server, and the browser connects to it.
  • Your Python never reaches the browser. NiceGUI turns it into the JSON tree shown under the code, and Vue + Quasar draw that tree.
  • Quasar sets box-sizing: border-box on every element, so each box is 200 px wide including its border. In Steps 1, 2 and 4 the border sits outside, making 204 px.
  • NiceGUI wraps your content in q-layout › q-page-container › q-page › nicegui-content. That wrapper adds 16 px of padding.

Run it

NiceGUI needs Python 3.10 or newer. On Arch Linux, pip refuses to install into the system Python, so use a virtual environment:

python -m venv .venv
source .venv/bin/activate
pip install nicegui
python step3_nicegui.py

Try it

Open the page source in your browser (Ctrl+U) and search for "elements". You will find the same JSON shown here.

4

Build the NiceGUI road by hand

Python + FastAPI + Vue 3 · step4_mini_nicegui.py

Rebuild what NiceGUI does in about 50 lines: a Python element tree, a server, JSON, and a Vue render function.

step4_mini_nicegui.py Python 
import json from fastapi import FastAPIfrom fastapi.responses import HTMLResponse  # ── Your code: the element tree (what NiceGUI's ui.* does) ──────────────class Element:    stack = []  # the element currently open in a `with` block     def __init__(self, tag, style=''):        self.tag, self.style, self.children = tag, style, []        if Element.stack:            Element.stack[-1].children.append(self)     def __enter__(self):        Element.stack.append(self)        return self     def __exit__(self, *_):        Element.stack.pop()     def to_dict(self):        return {'tag': self.tag, 'style': self.style,                'children': [c.to_dict() for c in self.children]}  RECT = 'width: 200px; height: 120px; border: 2px solid #333'  def build():    with Element('div', 'display: flex; gap: 16px') as root:  # row        Element('div', RECT)                                   # left        Element('div', RECT)                                   # right    return root  # ── Renderer: the browser page, where Vue turns the JSON into elements ──PAGE = """<!DOCTYPE html><html lang="en"><head><meta charset="UTF-8"><title>Step 4 – Mini NiceGUI</title></head><body>  <div id="app"></div>  <script type="module">    import { createApp, h } from 'https://unpkg.com/vue@3/dist/vue.esm-browser.prod.js'     const tree = __TREE__    const render = node => h(node.tag, { style: node.style }, node.children.map(render))     createApp({ render: () => render(tree) }).mount('#app')  </script></body></html>"""  # ── Server: sends the page with the tree inside as JSON ─────────────────app = FastAPI()  @app.get('/', response_class=HTMLResponse)def index():    return PAGE.replace('__TREE__', json.dumps(build().to_dict()))  if __name__ == '__main__':    import uvicorn    uvicorn.run(app, port=8080)

What the code does

  • Element.stack remembers which element is open in a with block. New elements become its children. This is how NiceGUI nesting works too.
  • to_dict() turns the whole tree into plain dicts, ready for json.dumps().
  • The server puts that JSON into the page in place of __TREE__.
  • h(tag, props, children) is Vue's way to create an element from code. render calls itself for each child, so any depth works.
  • Missing compared with NiceGUI: the websocket (Python can't change the page after it loads), Quasar components, and one tree per visitor.

Run it

On Arch Linux, use a virtual environment (FastAPI and uvicorn come with NiceGUI, or install them alone):

python -m venv .venv
source .venv/bin/activate
pip install fastapi uvicorn
python step4_mini_nicegui.py

Try it

Add a third Element('div', RECT) inside build() and reload. Then print(json.dumps(build().to_dict(), indent=2)) to see the tree.

Same road, no Python

HTML + Vue 3.5 + Quasar 2.35 · step5_vue_quasar.html

Keep NiceGUI's browser half (the same tree, Vue 3 and Quasar 2) and drop Python and NiceGUI completely.

step5_vue_quasar.html HTML 
<!DOCTYPE html><html lang="en"><head>  <meta charset="UTF-8">  <meta name="viewport" content="width=device-width, initial-scale=1">  <title>Step 5 – Same road as NiceGUI: Vue 3 + Quasar 2, no Python</title>   <!-- Same base NiceGUI loads in the browser -->  <link href="https://cdn.jsdelivr.net/npm/quasar@2/dist/quasar.prod.css" rel="stylesheet">  <script type="importmap">    { "imports": { "vue": "https://cdn.jsdelivr.net/npm/vue@3/dist/vue.esm-browser.prod.js" } }  </script>   <!-- The two NiceGUI CSS rules this layout uses (from nicegui.css) -->  <style>    .nicegui-content, .nicegui-row {      display: flex;      flex-direction: column;      align-items: flex-start;      gap: 1rem;    }    .nicegui-content { padding: 1rem; }    .nicegui-row     { flex-direction: row; }  </style></head><body>  <div id="app"></div>   <!-- 1. Vue as ES module, exposed globally for Quasar (exactly how NiceGUI does it) -->  <script type="module">    import * as Vue from 'vue'    globalThis.Vue = Vue  </script>   <!-- 2. Quasar UI library -->  <script defer src="https://cdn.jsdelivr.net/npm/quasar@2/dist/quasar.umd.prod.js"></script>   <!-- 3. Element tree → Vue + Quasar (what NiceGUI's Python server + nicegui.js do) -->  <script type="module">    import { createApp, h, resolveComponent } from 'vue'     const RECT = { width: '200px', height: '120px', border: '2px solid #333' }     // Same tree NiceGUI sends as JSON in Step 3    const tree =      { tag: 'q-layout', props: { view: 'hhh lpr fff' }, children: [        { tag: 'q-page-container', children: [          { tag: 'q-page', children: [            { tag: 'div', class: ['nicegui-content'], children: [              { tag: 'div', class: ['nicegui-row', 'row'], style: { gap: '16px' }, children: [                { tag: 'div', style: RECT },   // left                { tag: 'div', style: RECT },   // right              ]},            ]},          ]},        ]},      ]}     function render(node) {      const kids = () => (node.children ?? []).map(render)      const attrs = { class: node.class, style: node.style, ...node.props }      return node.tag.startsWith('q-')        ? h(resolveComponent(node.tag), attrs, { default: kids })  // Quasar component        : h(node.tag, attrs, kids())                              // plain HTML tag    }     createApp({ render: () => render(tree) }).use(Quasar).mount('#app')  </script></body></html>

What the code does

  • The import map lets the code say from 'vue'. Then globalThis.Vue = Vue exposes Vue for Quasar. NiceGUI does exactly this.
  • Quasar's UMD script registers q-layout, q-page and the other components once you call .use(Quasar).
  • render() sends q-* tags to resolveComponent() (Quasar components) and everything else to plain HTML tags.
  • Only the two NiceGUI CSS rules this layout needs are copied: .nicegui-content and .nicegui-row.
  • Checked in Chrome: this page and Step 3 produce the same pixels.

Run it

Open the file in a browser. It needs internet once, to fetch Vue and Quasar from the CDN.

Try it

Add { tag: 'q-btn', props: { label: 'Click me', color: 'primary' } } to the row's children. A real Quasar button appears.

Every road has a tree

Vue never draws your code directly. It always works from a tree of elements. In Steps 1–2 Vue builds that tree from your template. In Step 3 NiceGUI builds it in Python and sends it as JSON. In Steps 4–5 you build it yourself.

NiceGUI is Vue + Quasar with a Python front door

Step 5 proves it: the browser half of NiceGUI is just Vue 3, Quasar 2 and a render function. NiceGUI adds the Python API, the FastAPI server, and a websocket that keeps the page and Python in sync.

Next step to try

Make a rectangle clickable. In NiceGUI: ui.element('div').on('click', lambda: ui.notify('clicked')). In Step 4 you would need to add a websocket yourself. That is the biggest thing NiceGUI does for you.

The HTML samples load Vue with vue@3 and Quasar with quasar@2, which always give the newest release in that major version. In a real project, pin an exact version such as vue@3.5.44 so an update can't change your page unexpectedly.
