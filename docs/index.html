Quasar

Why the border goes inside

A browser counts the border outside the width by default. Then a 200 px box with a 2 px border is 204 px wide. box-sizing: border-box puts the border inside, so the box stays 200 px.

Quasar turns this on for every element, so NiceGUI has it too. In plain Vue you write it yourself. Here is the difference with a thick 8 px border, so you can see it:

How each column reaches the browser

All three files end as the same page, but they take different roads. NiceGUI is the only one with a server: your Python runs there, and the browser gets the page from it.

Quasar

Quasar's spacing classes

A spacing class has three parts: what (p padding, m margin), where (a all sides, x left and right, y top and bottom, t r b l one side), and how much. So q-pa-md is padding on all sides, medium; q-mt-lg is margin on the top, large. The sizes in Quasar 2.35:

Size none xs sm md lg xl
Space 0 4 px 8 px 16 px 24 px 48 px

They work in NiceGUI too, several at once: ui.element('div').classes('q-pa-md q-mt-lg').

Padding is the space inside a box, between its border and its content. Here are the same box and square with padding from xs to xl:

2.1

The element tree

Open this step on its own page ↗

Build the page from step 1.2 again, but write it as a tree: nodes with a tag, some settings and children.

Vue never draws your HTML directly. It always works from such a tree, and here you write the tree yourself. A render function turns it into the page.

NiceGUI builds the same tree from your with blocks and sends it to the browser. The real data it sends is below the screenshot.

2.2

Build a mini NiceGUI

Open this step on its own page ↗

NiceGUI has two halves: Python on a server builds the element tree, and Vue with Quasar draws it in the browser. Build both halves by hand.

The Vue 3 column is a mini NiceGUI in one Python file: a tree made with with blocks, a FastAPI server, and Vue to draw it. The Quasar column is the browser half on its own: it draws a tree written in NiceGUI's own format.

Read cross-comments 1 to 6 in order: they follow the road from your Python to the screen.

Two ways to change a page

Describe it (Quasar and Vue): you keep data, like count, and say how the page looks for that data (v-for="n in count"). Change the data, and Vue works out what to add or remove.

Change it (NiceGUI): you call Python that adds, moves or removes elements, like add(). NiceGUI sends each change to the browser.
