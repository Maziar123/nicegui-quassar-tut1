1.2

Two boxes side by side

Put two of the boxes from step 1.1 next to each other, with 16 px of space between them.

The new idea is a row: a box that puts its children side by side. All three columns use the same CSS underneath, called flexbox.

Look at cross-comments 2 and 4. NiceGUI's row already has the gap and the wrapping. Quasar has the wrapping. Plain Vue writes both.

A row is flexbox

display: flex turns a box into a row: its children line up side by side. Two more lines give it the gap and the wrapping. Quasar's row class and NiceGUI's ui.row() are this CSS with a name.

Here are three rows in a box only 380 px wide. The first has no gap, the second has a gap, and the third also wraps, so its last box moves to a new line:
