3.2

Add a box on each click

Start with one box. Every click on any box adds one more to the row.

Here the two ways of thinking split. Quasar and Vue keep a number and draw that many boxes. NiceGUI adds an element: Python makes one new box inside the row.

Both end with the same page, as the screenshot after one click shows.

Quasar

Two ways to change a page

Describe it (Quasar and Vue): you keep data, like count, and say how the page looks for that data (v-for="n in count"). Change the data, and Vue works out what to add or remove.

Change it (NiceGUI): you call Python that adds, moves or removes elements, like add(). NiceGUI sends each change to the browser.

NiceGUI can describe too. ui.refreshable draws a part of the page again from your data, like v-for:
