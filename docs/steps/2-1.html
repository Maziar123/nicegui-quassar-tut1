2.1

The element tree

Build the page from step 1.2 again, but write it as a tree: nodes with a tag, some settings and children.

Vue never draws your HTML directly. It always works from such a tree, and here you write the tree yourself. A render function turns it into the page.

NiceGUI builds the same tree from your with blocks and sends it to the browser. The real data it sends is below the screenshot.

Quasar quasar.html · HTML · 43 lines

The tree is plain JavaScript. render walks it: a tag that starts with q- becomes a Quasar component, any other tag a plain HTML element.

NiceGUI nicegui_app.py · Python · 12 lines

The same Python as step 1.2. Each with opens a node, and each element inside it becomes a child.

What NiceGUI sends to the browser

This is the tree NiceGUI 4.0.0 sent for the NiceGUI column, taken from a real run (empty fields left out). It is one flat list, numbered: children holds the numbers of the child nodes, not the nodes themselves.

Drawn as a tree, it is the same shape as the Quasar column's tree. NiceGUI adds one node of its own, the content area nicegui-content, which gives the page its 16 px padding:
