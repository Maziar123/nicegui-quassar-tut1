{% call m.card("Why the border goes inside", "aside") %}

A browser counts the border outside the width by default. Then a 200 px box with a 2 px border is 204 px wide. box-sizing: border-box puts the border inside, so the box stays 200 px. Quasar turns this on for every element, so NiceGUI has it too. In plain Vue you write it yourself.
